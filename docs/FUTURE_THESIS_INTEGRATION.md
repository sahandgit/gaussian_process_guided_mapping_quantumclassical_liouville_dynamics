# Future Thesis Integration

This repository is currently a standalone research-software pipeline. It should not assume that a thesis or paper already exists.

Recommended later steps:

1. Keep the main branch as the stable research pipeline.
2. Add thesis-specific figure-generation scripts only after the thesis figures are finalized.
3. Add a `thesis/` directory or a separate `thesis-integration` branch if needed.
4. Record the exact commands and commit hashes used for thesis figures.
5. Update `CITATION.cff` after the thesis is complete.
6. Consider archiving a release with Zenodo after validation and thesis completion.
